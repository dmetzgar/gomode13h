This is my personal site: blog posts, plus a few areas for experiments.

The first experiment is the [mode 13h playground]({{< relref "playground.md" >}}), an 8086 and VGA emulator that runs in the browser.
I didn't see any good mode 13h/8086 emulators out there, so I made one with Claude and shared it here.

The site is entirely static HTML, and the code behind it is [on GitHub](https://github.com/dmetzgar/gomode13h).
